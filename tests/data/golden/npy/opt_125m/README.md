# opt-125m Golden Outputs (NPY Format)

Per-function golden outputs for opt-125m, organized by sequence length configuration.

## Structure

```
opt_125m/
├── configs.json         # Multi-config test matrix (created by Task 2)
├── README.md            # This file
├── seq1/                # Golden .npz files for seq_len=1
├── seq2/                # Golden .npz files for seq_len=2
├── seq6/                # Golden .npz files for seq_len=6
└── seq32/               # Golden .npz files for seq_len=32
```

## .npz Files

- Each `.npz` file contains golden tensor outputs for a specific function in the compiled model.
- Files are indexed by function symbol name, matching the generated `configs.json`.
- Git LFS managed: `tests/data/golden/npy/**/*.npz filter=lfs` in root `.gitattributes`.

## Usage

```python
import numpy as np

data = np.load("tests/data/golden/npy/opt_125m/seq6/some_function.npz")
for key in data.files:
    print(key, data[key].shape)
```

## Regeneration

Golden outputs are generated by `compiler/tests/generate_golden_outputs.py` (Task 4) and must be regenerated whenever the compilation pipeline changes.
